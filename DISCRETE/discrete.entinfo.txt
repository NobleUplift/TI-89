()
Prgm
© entinfo: harness for Shannon entropy & information gain UI.
© F1 Entropy, F2 I.G., F3 About/Quit -- see DISCRETE/README.md.
© The actual math lives in discrete\entropy(counts) and discrete\tally(rawLabels), called from every path here instead of being duplicated.
© p: counts/probabilities fed to entropy()
© r: raw labels, or an attribute column in auto
© n: total count, sum(p)
© i: loop index, auto's grouping pass
© cur: attribute value of the current group
© res: parent/manual entropy result {h,n}
© res2: subset or uniform-max entropy result {h,n}
© mx: max (uniform) entropy, for efficiency %
© k: number of subsets, gain's manual entry
© j: loop index over subsets
© all: pooled labels from every subset
© sumnh: running Σ n(subset)*H(subset)
© wtd: weighted average subset entropy
© y: class labels, auto's second column
© child: current subset's labels, auto
© em: caller's Exact/Approx mode, restored on quit
Local p,r,n,i,cur,res,res2,mx,k,j,all,sumnh,wtd,y,child,em

© force Approximate so ln() in entropy() always evaluates to a
© decimal instead of possibly staying symbolic through the loop;
© restored at Lbl quit so entinfo doesn't change the caller's mode
getMode("Exact/Approx")→em
setMode("Exact/Approx","Approximate")

© ClrIO once, to clear whatever ran before us. From here on entinfo
© owns the I/O screen and never blind-clears it again -- each path
© below only clears/prints exactly what it needs to, and no path
© Pauses: it prints its result (or error) and returns to the toolbar.
ClrIO
Disp "Shannon Entropy: "
Disp "H(S) = -Σ p·log2(p)"
Disp "Information Gain: "
Disp "Gain = H(S) - Σ(n/N)·H(child)"

Lbl top
Toolbar
 Title "Entropy"
  Item "Manual",ask
  Item "Automatic",tally
 Title "I.G."
  Item "Manual",gain
  Item "Automatic",auto
 Title "About"
  Item "About",about
  Item "Quit",quit
EndTBar
Goto top

Lbl ask
Input "Counts, e.g. {16,14}",p
Goto calc

Lbl tally
Input "Labels {1,1,2} or db[col]",r
If getType(r)≠"LIST" Then
 Disp "Err: need {1,1,2}/db[col]"
 Goto top
EndIf
If dim(r)<1
 Goto top
discrete\tally(r)→p

Lbl calc
If getType(p)≠"LIST" Then
 Disp "Err: need {16,14}"
 Goto top
EndIf
If dim(p)<1 or min(p)<0
 Goto top
sum(p)→n
If n≤0
 Goto top
discrete\entropy(p)→res
discrete\entropy(newList(dim(p))+1)→res2
res2[1]→mx

ClrIO
Disp "H(S) = "&string(round(res[1],4))&" bits"
If mx>0
 Disp "Max (uniform) = "&string(round(mx,4))&" bits","Efficiency = "&string(round(100*res[1]/mx,2))&"%"
Goto top

Lbl gain
Input "Number of subsets",k
If k<2
 Goto top
{}→all
0→sumnh
For j,1,k
 ClrIO
 Disp "Subset "&string(j)&" of "&string(k)
 Input "Labels {1,1,2} or db[col]",r
 If getType(r)≠"LIST" Then
  Disp "Err: need {1,1,2}/db[col]"
  Goto top
 EndIf
 If dim(r)<1
  Goto top
 augment(all,r)→all
 discrete\entropy(discrete\tally(r))→res
 sumnh+res[2]*res[1]→sumnh
EndFor

discrete\entropy(discrete\tally(all))→res
sumnh/res[2]→wtd
Goto showgain

Lbl auto
Input "Attribute col, e.g. db[1]",r
Input "Class col, e.g. db[2]",y
If getType(r)≠"LIST" Then
 Disp "Err: attrib needs list/db[col]"
 Goto top
EndIf
If getType(y)≠"LIST" Then
 Disp "Err: class needs list/db[col]"
 Goto top
EndIf
If dim(r)<1 or dim(r)≠dim(y)
 Goto top

© parent entropy from the whole class column; tally(y) only reads y, so it stays row-aligned with r for the grouping pass below
discrete\entropy(discrete\tally(y))→res

© group rows into subsets by attribute value: sorting r,y together keeps each class label attached to its own row's attribute value
SortA r,y
{y[1]}→child
r[1]→cur
0→sumnh
For i,2,dim(r)
 If r[i]=cur Then
  augment(child,{y[i]})→child
 Else
  If dim(child)<1 Then
   Disp "Err: empty subset at i="&string(i)
   Goto top
  EndIf
  discrete\entropy(discrete\tally(child))→res2
  sumnh+res2[2]*res2[1]→sumnh
  {y[i]}→child
  r[i]→cur
 EndIf
EndFor

© finalize the last (trailing) subset
If dim(child)<1 Then
 Disp "Err: empty subset at end"
 Goto top
EndIf
discrete\entropy(discrete\tally(child))→res2
sumnh+res2[2]*res2[1]→sumnh

sumnh/dim(y)→wtd

Lbl showgain
ClrIO
Disp "Parent H = "&string(round(res[1],4))&" bits"
Disp "Wtd H    = "&string(round(wtd,4))&" bits"
Disp "Gain     = "&string(round(res[1]-wtd,4))&" bits"
Goto top

Lbl about
Dialog
 Title "Shannon Entropy"
 Text "Entropy & information gain"
 Text "for the TI-89"
 Text "By Patrick Seiter and"
 Text "Claude (Anthropic), 2026"
EndDlog
Goto top

Lbl quit
setMode("Exact/Approx",em)
ClrIO
DispHome
EndPrgm
