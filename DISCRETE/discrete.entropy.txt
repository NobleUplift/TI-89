()
Prgm
© entropy: Shannon entropy H(S) = -Σ p·log2(p)
© F1 Entropy menu:
©  Manual: type counts or probabilities as a list, in
©   braces, e.g. {16,14} or {.25,.25,.5}. For learning
©   the arithmetic once you've counted by hand.
©  Automatic: type one raw label per sample as a list,
©   in braces, e.g. {1,1,1,2,2}, or a Data variable
©   column (e.g. mydata[1]) in place of a literal list
©   -- Input evaluates whatever is typed. Tallies
©   occurrences of each distinct value itself before
©   computing H.
© F2 I.G. (information gain) menu, for a split into
© several children:
©  Manual: asks how many children, then each child's
©   raw labels (literal list or db[col], same as F1's
©   Automatic).
©   You decide which rows belong to which child; the
©   parent is never entered separately, since pooling
©   all children's labels reconstructs it exactly. For
©   learning how a split's gain is actually assembled.
©  Automatic: asks for a whole attribute column and a
©   whole class-label column (e.g. mydata[1], mydata[2]);
©   groups rows into children by matching attribute
©   value itself (SortA on both together keeps each row's
©   class label attached to its attribute value), so no
©   manual grouping at all. Deliberately plain Data-column
©   Input, not the combined Matrix built for viewing the
©   whole table: a Matrix's column extraction isn't a
©   verified primitive here, while db[col] already is.
© F3: About (credits) and Quit. Every top-level Title has
© Items nested under it, including this one, matching
© this repo's own convention (see discrete\baseconv):
© a Title is always a menu to open, never an action by
© itself.
© Uses Input, not Request: Request's dialog starts in
© Alpha-Lock (meant for names), forcing Alpha off before
© every numeric entry. Input's entry line starts in
© normal mode, like the Home screen, so digits and { }
© type directly; only cost is typing the braces yourself.
Local p,r,c,n,i,m,cur,cur2,h,h2,mx,k,j,all,sumnh,wtd,y,yp,child

Lbl top
ClrIO
Disp "Shannon Entropy","H(S) = -Σ p·log2(p)","F1: Entropy  F2: I.G.","F3: About/Quit"
Toolbar
Title "Entropy"
Item "Manual",ask
Item "Automatic",tally
Title "I.G."
Item "Manual",gain
Item "Automatic",auto
Title "About"
Item "About",about
Item "Quit",quit
EndTBar
Goto top

Lbl ask
Input "Counts, e.g. {16,14}",p
Goto calc

Lbl tally
Input "Labels or db[col]",r
If dim(r)<1
Goto top
SortA r
{1}→c
r[1]→cur
For i,2,dim(r)
If r[i]=cur Then
c[dim(c)]+1→c[dim(c)]
Else
augment(c,{1})→c
r[i]→cur
EndIf
EndFor
c→p

Lbl calc
If dim(p)<1 or min(p)<0
Goto top
sum(p)→n
If n≤0
Goto top
p/n→p

0→h
For i,1,dim(p)
If p[i]>0
h-p[i]*ln(p[i])/ln(2)→h
EndFor

If dim(p)>1
ln(dim(p))/ln(2)→mx
If dim(p)=1
0→mx

ClrIO
Disp "H(S) = "&string(round(h,4))&" bits"
If mx>0
Disp "Max (uniform) = "&string(round(mx,4))&" bits","Efficiency = "&string(round(100*h/mx,2))&"%"
Pause
Goto top

Lbl gain
Input "Number of children",k
If k<2
Goto top
{}→all
0→sumnh
For j,1,k
ClrIO
Disp "Child "&string(j)&" of "&string(k)
Input "Labels or db[col]",r
If dim(r)<1
Goto top
augment(all,r)→all
SortA r
{1}→c
r[1]→cur
For i,2,dim(r)
If r[i]=cur Then
c[dim(c)]+1→c[dim(c)]
Else
augment(c,{1})→c
r[i]→cur
EndIf
EndFor
sum(c)→n
c/n→p
0→h
For i,1,dim(p)
If p[i]>0
h-p[i]*ln(p[i])/ln(2)→h
EndFor
sumnh+n*h→sumnh
EndFor

SortA all
{1}→c
all[1]→cur
For i,2,dim(all)
If all[i]=cur Then
c[dim(c)]+1→c[dim(c)]
Else
augment(c,{1})→c
all[i]→cur
EndIf
EndFor
sum(c)→n
c/n→p
0→h
For i,1,dim(p)
If p[i]>0
h-p[i]*ln(p[i])/ln(2)→h
EndFor
sumnh/n→wtd

ClrIO
Disp "Parent H = "&string(round(h,4))&" bits","Weighted child H = "&string(round(wtd,4))&" bits","Gain = "&string(round(h-wtd,4))&" bits"
Pause
Goto top

Lbl auto
Input "Attribute col, e.g. db[1]",r
Input "Class col, e.g. db[2]",y
If dim(r)<1 or dim(r)≠dim(y)
Goto top

© parent entropy: tally a sorted copy of y, so y itself
© stays row-aligned with r for the grouping pass below
y→yp
SortA yp
{1}→c
yp[1]→cur
For i,2,dim(yp)
If yp[i]=cur Then
c[dim(c)]+1→c[dim(c)]
Else
augment(c,{1})→c
yp[i]→cur
EndIf
EndFor
sum(c)→n
c/n→p
0→h
For i,1,dim(p)
If p[i]>0
h-p[i]*ln(p[i])/ln(2)→h
EndFor

© group rows into children by attribute value: sorting
© r,y together keeps each class label attached to its
© own row's attribute value
SortA r,y
{y[1]}→child
r[1]→cur
0→sumnh
For i,2,dim(r)
If r[i]=cur Then
augment(child,{y[i]})→child
Else
SortA child
{1}→c
child[1]→cur2
For m,2,dim(child)
If child[m]=cur2 Then
c[dim(c)]+1→c[dim(c)]
Else
augment(c,{1})→c
child[m]→cur2
EndIf
EndFor
sum(c)→n
c/n→p
0→h2
For m,1,dim(p)
If p[m]>0
h2-p[m]*ln(p[m])/ln(2)→h2
EndFor
sumnh+n*h2→sumnh
{y[i]}→child
r[i]→cur
EndIf
EndFor

© finalize the last (trailing) child
SortA child
{1}→c
child[1]→cur2
For m,2,dim(child)
If child[m]=cur2 Then
c[dim(c)]+1→c[dim(c)]
Else
augment(c,{1})→c
child[m]→cur2
EndIf
EndFor
sum(c)→n
c/n→p
0→h2
For m,1,dim(p)
If p[m]>0
h2-p[m]*ln(p[m])/ln(2)→h2
EndFor
sumnh+n*h2→sumnh

sumnh/dim(y)→wtd

ClrIO
Disp "Parent H = "&string(round(h,4))&" bits","Weighted child H = "&string(round(wtd,4))&" bits","Gain = "&string(round(h-wtd,4))&" bits"
Pause
Goto top

Lbl about
Dialog
Title "Shannon Entropy"
Text "Entropy & information gain"
Text "for the TI-89"
Text "By Patrick Seiter and"
Text "Claude (Anthropic), 2026"
EndDlog
Goto top

Lbl quit
ClrIO
DispHome
EndPrgm
