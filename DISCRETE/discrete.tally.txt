(r)
Func
© v: distinct values seen so far
© c: matching counts, returned
© i: loop index over r
© j: loop index over v
© found: 1 if r[i] matched an existing v
Local v,c,i,j,found
{}→v
{}→c
For i,1,dim(r)
 0→found
 For j,1,dim(v)
  If r[i]=v[j] Then
   c[j]+1→c[j]
   1→found
  EndIf
 EndFor
 If found=0 Then
  augment(v,{r[i]})→v
  augment(c,{1})→c
 EndIf
EndFor
Return c
EndFunc
